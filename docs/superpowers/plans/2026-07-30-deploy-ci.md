## Tasks

### 1. Add `.github/workflows/ci.yml`

- Create `.github/workflows/ci.yml` with `pull_request` + `push` to `main` triggers.
- Single job: Node 20, `npm ci`, then fail-fast `lint` → `test` → `tsc --noEmit` → `build`.
- Dummy `env:` block with all variables `parseEnvInput` requires (see design spec for table).
- Cache: `actions/setup-node@v4` with `cache: npm`.
